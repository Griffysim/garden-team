# Quick Start

1. Create a Neon project.
2. Run `database/schema.sql` in Neon SQL Editor.
3. Copy the pooled Neon connection string.
4. Upload this project to GitHub.
5. Import the GitHub repository into Netlify.
6. Add `DATABASE_URL` and a 32+ character `JWT_SECRET` to Netlify environment variables with Functions access.
7. Deploy.
8. Log in using the temporary Simon, Msesa and Karen accounts listed in `README.md`.
9. Change all three passwords immediately.
10. Test one task, daily log, message, machine record, vegetable record and accommodation request.

The site is designed for phones as well as computers. Msesa can use it from a mobile browser without installing an app.
